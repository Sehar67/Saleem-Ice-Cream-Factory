# 🍦 Saleem's Ice Cream Factory Website

A complete Ice Cream Factory E-commerce Website developed using PHP and MySQL.

This project allows customers to explore ice cream products, create accounts, place orders, submit reviews, and contact the factory. It also includes a complete admin panel for managing products, orders, customers, messages, and reports.

---

## 🚀 Features

### 👤 User Side

- User Signup and Login
- User Profile
- Browse Ice Cream Products
- Product Details
- Add to Cart
- Update Cart Quantity
- Place Orders
- Order Management
- Contact Form
- Customer Reviews


### 🔐 Admin Panel

- Admin Login
- Dashboard
- Product Management
  - Add Products
  - Edit Products
  - Delete Products
- Order Management
- Customer Management
- Messages View
- Reviews Management
- Reports
- Logout
